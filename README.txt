# Portal Anti-Bullying

Página web educativa basada en el informe del proyecto de innovación:

“PORTAL WEB DE PREVENCIÓN Y CONCIENTIZACIÓN SOBRE EL BULLYING”

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño visual y adaptación a celular.
- `script.js` — menú móvil, recursos interactivos, ventanas informativas y quiz.

## Cómo abrir

Abrir `index.html` con Chrome, Edge o Firefox.

## Contenido incorporado

- Definición de bullying.
- Formas de acoso: verbal, físico, social y psicológico.
- Consecuencias y prevención.
- Ciberbullying y educación digital.
- Convivencia escolar y empatía.
- Recursos educativos.
- Secciones dirigidas a estudiantes, docentes y familias.
- Quiz interactivo de repaso.

## Nota

El contenido se construyó tomando como base el informe proporcionado. Las funciones interactivas son una propuesta de implementación del portal descrito en el proyecto.
